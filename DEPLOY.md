# Деплой на Railway — пошаговая инструкция

Занимает около 10 минут. Делай по порядку.

---

## Шаг 1 — Создай аккаунт на GitHub

1. Зайди на **github.com** и зарегистрируйся (если нет аккаунта)
2. Подтверди email

---

## Шаг 2 — Загрузи проект на GitHub

1. Зайди на **github.com** → нажми **«+»** → **«New repository»**
2. Название: `wedding`
3. Выбери **Public**
4. Нажми **«Create repository»**
5. На следующей странице нажми **«uploading an existing file»**
6. Открой папку `wedding-main` в проводнике
7. Выдели **все файлы и папки** внутри (Ctrl+A) и перетащи в браузер
8. Подожди пока загрузятся
9. Внизу нажми **«Commit changes»**

---

## Шаг 3 — Создай аккаунт на Railway

1. Зайди на **railway.app** (через VPN)
2. Нажми **«Login»** → **«Login with GitHub»**
3. Разреши доступ

> После этого Railway будет работать без VPN — он размещён на серверах вне России.
> Гостям VPN не нужен, тебе нужен только при первой настройке.

---

## Шаг 4 — Создай проект на Railway

1. На главной Railway нажми **«New Project»**
2. Выбери **«Deploy from GitHub repo»**
3. Нажми **«Configure GitHub App»** → выбери свой репозиторий `wedding`
4. Нажми **«Deploy Now»**
5. Railway автоматически найдёт `package.json` и запустит сервер

---

## Шаг 5 — Добавь переменную окружения (ВАЖНО!)

Это нужно чтобы сервер знал куда отправлять данные гостей.

1. В Railway открой свой проект
2. Нажми на сервис (появится карточка с логами)
3. Перейди во вкладку **«Variables»**
4. Нажми **«New Variable»**
5. Заполни:
   - **Name:** `GOOGLE_SCRIPT_URL`
   - **Value:** `https://script.google.com/macros/s/AKfycbxs-5RGiv20EIN-qe4g2BC7HHPFy8NdE9x6IAX-m4RoPvaVQdLDi6Q1zBUXzSkpWdGH/exec`
6. Нажми **«Add»**
7. Railway автоматически перезапустит сервер

---

## Шаг 6 — Получи ссылку для гостей

1. В Railway перейди во вкладку **«Settings»**
2. Найди раздел **«Networking»** → **«Public Networking»**
3. Нажми **«Generate Domain»**
4. Получишь ссылку вида: `wedding-production-xxxx.up.railway.app`

Эту ссылку отправляй гостям — она открывается без VPN на любом телефоне.

---

## Шаг 7 — Проверь что всё работает

1. Открой полученную ссылку в браузере (можно без VPN)
2. Введи тестовое ФИО и нажми «Приду»
3. Убедись что появилось сообщение «Спасибо»
4. Открой Google Таблицу — должна появиться строка с данными

---

## Схема как это работает

```
Гость (без VPN)
    ↓
Railway сервер (вне России)
    ↓  POST /api/rsvp
Express (server.js)
    ↓  проксирует запрос
Google Apps Script
    ↓
Google Sheets — данные сохранены ✓
```

Гости не обращаются к Google напрямую — за них это делает сервер Railway.
Поэтому VPN гостям не нужен.

---

## Если нужно обновить сайт

1. Измени файлы в папке `wedding-main`
2. Зайди в GitHub → открой репозиторий `wedding`
3. Нажми на файл который хочешь обновить → карандаш ✏️ → вставь новый код → **Commit**
4. Railway автоматически подхватит изменения и перезапустится

---

## Частые вопросы

**Сколько стоит Railway?**
Есть бесплатный план — $5 кредитов в месяц, для небольшого сайта хватит на несколько месяцев.

**Ссылку можно сделать красивее?**
Да — в Railway в разделе Settings → Custom Domain можно привязать свой домен,
например купленный на reg.ru (`wedding-george-nastya.ru`).

**Данные в таблице не появляются?**
Проверь что переменная `GOOGLE_SCRIPT_URL` добавлена правильно во вкладке Variables.
