# Настройка Google Apps Script для формы RSVP

Пошаговая инструкция — займёт около 5–7 минут.

---

## Шаг 1 — Создайте Google Таблицу

1. Откройте [Google Sheets](https://sheets.google.com) и создайте новую таблицу.
2. Назовите её, например: **«Гости свадьбы Георгия и Анастасии»**.
3. Скопируйте **ID таблицы** из адресной строки браузера:

```
https://docs.google.com/spreadsheets/d/  ВОТ_ЭТОТ_КОД  /edit
```

---

## Шаг 2 — Создайте Apps Script

1. В таблице откройте меню **Расширения → Apps Script**.
2. Удалите весь существующий код в редакторе.
3. Скопируйте содержимое файла **`Code.gs`** из этой папки и вставьте в редактор.
4. В строке `var SPREADSHEET_ID = '...'` вставьте ID вашей таблицы (скопированный на шаге 1).
5. Нажмите **Ctrl+S** (или кнопку 💾), чтобы сохранить.

---

## Шаг 3 — Задеплойте скрипт

1. Нажмите кнопку **«Развернуть»** (Deploy) → **«Новое развёртывание»**.
2. Нажмите шестерёнку ⚙️ рядом с «Тип» → выберите **«Веб-приложение»**.
3. Заполните настройки:
   - **Описание**: `Wedding RSVP v1`
   - **Выполнять как**: `Я` (от вашего аккаунта)
   - **Кто имеет доступ**: `Все` (**Все, включая анонимных**)
4. Нажмите **«Развернуть»**.
5. Google попросит разрешения — нажмите **«Разрешить»** и пройдите авторизацию.
6. Скопируйте **URL веб-приложения** — он выглядит так:

```
https://script.google.com/macros/s/AKfycb.../exec
```

---

## Шаг 4 — Вставьте URL в сайт

1. Откройте файл `index.html`.
2. Найдите строку (около строки 135):

```javascript
var SCRIPT_URL = 'ВСТАВЬТЕ_URL_GOOGLE_APPS_SCRIPT_ЗДЕСЬ';
```

3. Замените текст-заглушку на ваш URL:

```javascript
var SCRIPT_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
```

4. Сохраните файл.

---

## Шаг 5 — Проверьте работу

1. Откройте сайт в браузере.
2. Введите тестовое ФИО и нажмите «Приду».
3. Убедитесь, что появилось сообщение об успехе.
4. Откройте Google Таблицу — должна появиться строка с данными.

## Частые проблемы

**Ошибка «Ошибка соединения»** — убедитесь, что в настройках деплоя выбрано
«Кто имеет доступ: Все». При изменении кода нужно создавать **новое развёртывание**,
а не обновлять старое — URL останется прежним только если выбрать «Управление
развёртываниями → Изменить → Версия: Новая версия».

**Данные не попадают в таблицу** — проверьте, что `SPREADSHEET_ID` в `Code.gs`
соответствует ID вашей таблицы. ID не должен содержать лишних символов.
